# 当前实现基准

本页解释仓库现在实际执行的机制。与以前 PR 的文字冲突时，以本次代码为准；历史记录保留当时的口径，不作为运行规范。

## 一条流程看懂

每个类别独立运行：**预训练模型检测 → 复核并积累真实缺陷 → 训练 YOLO 候选 → 校准阈值 → 影子推理 → 根据真实复核结果决定是否替换正式模型**。

正式模型负责当批输出，影子模型同时预测但不影响输出。校准只回答“这个模型用什么阈值”；影子评估才回答“是否用它替换正式模型”。独立测试集只报告效果，不参与这两个决定。

## 冷启动、复核和训练

- 冷启动不需要 NG：DINOv2 + ADPretrain 残差特征、PatchCore 正常记忆库提供异常分数和粗分割。随真实 NG 积累重新校准分类阈值。
- 正式模型判 NG 的图片全部复核；判 OK 的图片按得分分层抽检。未复核 OK 可作为训练伪标签，不能充当评测或校准真值。
- 确认 NG 达到 40 张开始训练 YOLO26s-seg；随后按配置中的 NG 里程碑重训。同批跨过多个里程碑，只训练最高的一个。版本 `vN` 表示触发时的 NG 里程碑，不是训练轮数，也不等于实际入训 NG 数。
- 真实 NG 按哈希固定分到训练/校准；初始化校准 OK 永不入训。外圆按固定 ROI 处理，完全在 ROI 外的缺陷不计入有效评测。
- 默认每个候选训练 100 轮、输入 1024、batch 4、seed 42，使用 `last.pt`，不按验证损失选择最佳轮次。之后校准图像阈值和掩膜置信度，并做加载及单图推理检查。

详细参数与抽检比例见 [LIFECYCLE.md](LIFECYCLE.md)。固定种子有助于复现，但不意味着更换硬件或训练数据后结果完全相同。

## 候选怎样切换

所有完成校准和推理检查的候选直接进入影子，**不再进行离线 C/T₅ 比较或离线否决**。

影子累计至少 10 张有效复核 NG，或运行满 5 批，进行一次比较。双方使用同一批配对、无重复、包含 OK 和 NG 的真实复核样本。缺失指标不能按零处理；例如全是 NG 的窗口无法评价误报，不能批准切换。

错误成本定义为 **C = 2 × 漏检数 FN + 误报数 FP**，数值越低越好。以下任一条件满足即可切换：

| 条件 | 含义 |
|---|---|
| 新 C < 旧 C | 按一次漏检折算两次误报，整体错误成本降低 |
| 新 C = 旧 C，且新 T₅ > 旧 T₅ | 分类成本持平，选择定位更好的模型 |
| 新 T₅ − 旧 T₅ ≥ 0.20 | 分割改善至少 20 个百分点，即使 C 上升也允许切换 |

最后一条的 20 指**百分点**，不是相对提高 20%。没有隐藏的“FN/FP 必须分别不增加”否决条件；这是一项明确的业务取舍，不保证所有指标都改善。代码用原始整数像素计数比较比例，不用显示时四舍五入的百分比。

例如第 2 批结束训练出候选，它在第 3 批做影子；第 3 批结束才有这批的复核证据，若通过则后续输入使用新正式模型。第 3 批的在线记录仍属于实际输出它的旧正式模型，不能事后改写。新里程碑到来会替换尚未完成的旧影子窗口；流结束时证据不足的候选保留影子状态，不强制上线。

实现入口：[`promotion.py`](../src/detected_pipeline/promotion.py)、[`run_lifecycle.py`](../cli/run_lifecycle.py)。规则标识：`shadow_cost_t5_capped_gain20_v3`。

## IoU、T₅ 与完整在线指标

IoU 保留原定义：有效真实 NG 的预测与 GT **交集总像素 / 并集总像素**。分类漏检按空预测计算，因此漏掉的 GT 仍进入分母。

T₅ 允许原图上 5 像素的 Chebyshev 距离，即 11×11 方形邻域；同时限制过度分割带来的惩罚。对每张有效 NG：

- A：GT 缺陷面积。
- M₅：距离预测超过 5 像素的 GT 面积，表示未覆盖的缺陷。
- E₅：距离 GT 超过 5 像素的预测面积，表示多预测的区域。
- **T₅ = Σ(A − M₅) / Σ(A + min(E₅, A))**，先逐图封顶，再汇总。

完全漏检为 0；全部缺陷被覆盖但存在大量多预测时可得到 0.5。超过封顶的多预测面积不再继续拉低 T₅，这是它与 IoU 的有意区别，也因此必须同时保留 IoU。T₅ 不是纯像素召回率。

完整在线指标使用各批当时正式模型的真实预测：FN/FP/TP/TN 相加，再算 Recall、FPR 和 C；IoU/T₅ 汇总各自像素分子分母。**不平均逐图或逐批百分比**。FPR 是误报率 `FP/(FP+TN)`，不是 FRP。

必须分开阅读三种范围：在线审核子集、仿真结束后读取完整真值的在线流、独立测试集。仿真事后统计的隐藏真值不回传训练或切换。独立展示先列初始预训练，再明确列出每个 YOLO 版本；最新候选不一定是正式模型。同名预训练模型在不同批次可能使用重新校准后的阈值。

像素定义与缓存说明见 [METRICS.md](METRICS.md)。指标版本 `tolerant_agreement_r5_chebyshev_capped_v2`；schema 4。旧 T₅ 的百分比不能直接转换为新值，必须从真实掩膜重新计算。

## 默认启用的伪缺陷增强

默认开启；运行前需配置独立生成后端，缺失配置会在初始化前报错。仅用当前真实训练 NG 和可信 OK 作为生成支持；生成图片只进入当轮 YOLO 训练，不进入校准、影子真值或测试集。限制包括每轮最多 20 张、不超过真实训练 NG 的 10%、不超过总训练量的 3%，每类最多 8 次生成。

生成后端独立部署，源码用散列固定；主线保存支持来源、请求/产物散列、实际入训清单及跳过原因。预算不等于实际入训数；缓存支持不再属于当前训练集时可能加入 0 张。细节见 [SYNTHETIC_AUGMENTATION.md](SYNTHETIC_AUGMENTATION.md)。

## 配置、运行与验证边界

| 文件 | 职责 |
|---|---|
| `configs/pipeline.yaml` | 复核、里程碑、影子窗口与分类阈值目标 |
| `configs/pretrained.yaml` | 冷启动模型、热力图和粗分割 |
| `configs/training.yaml` | YOLO 训练和推理参数 |
| `configs/synthetic.yaml` | 默认开启的限额生成接口 |
| `configs/simulation.yaml`、`configs/roi.yaml` | 仿真数据入口和固定检测域 |

未增强对照须显式选择 `configs/synthetic_baseline.yaml`，并使用新结果目录。

运行入口见 [WINDOWS_SETUP.md](WINDOWS_SETUP.md)。脚本默认使用当前环境的 `python`；数据默认放 `data/dataset_523`，可通过 `-DatasetRoot` 或 `--dataset-root` 显式指定，输出留在 `results/`。

`run_table_experiment.py` 是隔离源码快照的实验入口，需要预先准备 `experiment_source.json`。其 smoke 阶段显式接收 `--dataset-root` 和 `--weights-archive`（ZIP 内为 `models/<权重名>`），可选 `--amp-checkpoint`；smoke 为 1 轮连通性检查，不代表正式 100 轮实验通过。

规则单测覆盖容差边界、漏检空掩膜、逐图封顶/跨批汇总、成本取舍与恰好 20 个百分点；生命周期集成测试使用模拟训练/推理，验证直接进入影子、批次切换、状态保存和续跑。它们不替代真实 GPU 训练。

旧训练轨迹的完整实验与**固定模型回放**也须分开：回放复用已有模型，只补正式/影子推理，能比较固定模型下的切换轨迹，不能证明新规则引起的后续复核、训练集和重训结果。改变规则后的完整闭环应使用新的工作区。

仓库只保存源码、配置、测试、说明和必需 ROI；权重、数据、工作区状态、服务器调度脚本、日志及结果表不随 PR 上传。
