# 模型切换纳入 micro IoU，并移除 1 个百分点误报改善门槛

> 历史记录：用于追溯当时的实验与规则，不是当前运行规范。当前实现以[基准说明](../BASELINE.md)和代码为准。

旧规则只比较漏检和误报。新 YOLO 即使分类与旧模型相同、分割明显更好，也会被拒绝；低误报场景的小幅改善也可能被固定 0.01 门槛挡住。

新规则在校准集离线比较与在线影子裁决中保持一致：漏检和误报张数不增加，Recall、OK 误报率、micro IoU 全部不变坏，且至少一项严格改善。完全相同仍保留旧模型。IoU 为 ROI 内有效 NG 的端到端 micro IoU，漏检贡献完整 GT 并集，不使用逐图均值或批次均值。

例如，旧模型 0 漏检、1/200 误报、micro IoU 0.30：新模型同样分类而 IoU 提高到 0.60 可以通过；IoU 不变但误报降至 0 也可以通过；即便分类改善，只要 micro IoU 下降仍拒绝。

实现新增独立 promotion 模块，离线现场预测相同校准样本，影子状态保存配对样本的像素计数。原有审核统计复用同一计数逻辑。报告保留规则版本、检查项、双方指标、改善项和拒绝原因。

缺失指标不冒充零分：无有效 NG/OK、GT 或预测缺失均不能通过；旧影子状态和旧离线结论不能直接批准新规则上线。推荐独立新工作区验证，历史实验与正式模型不会被自动改写。

训练节点、训练参数、阈值选择、复核抽样、新候选替换旧候选的机制保持；影子 NG 计数遵循评测 ROI/有效 GT 范围。固定测试集仍然仅用于报告，不参与切换。

回归验证涵盖：只改善 IoU、只改善召回、低于 1 个百分点的误报改善、任一指标退步、完全相同、空类别/缺失 GT/缺失预测、ROI、漏检空掩膜、跨批 micro 汇总、旧状态保护，以及模拟训练/推理的真实生命周期与重启续跑。模拟不替代真实 GPU 性能实验。
